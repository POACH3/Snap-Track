# Minor changes: offer lint, test, and build, don't run them

For a minor change, do not run lint, tests, or build on your own. Make the
change, say what changed, and offer to run the checks. Run them only if the
developer says yes.

Minor means: text or copy edits, CSS or styling tweaks, comments, renames
of a single local variable, docs, and other edits of a few lines that do
not change types, exports, or logic.

Run the checks in AGENTS.md "Definition of done" without being asked only
when the change is not minor or at the end of a larger piece of work. When
unsure whether a change is minor, treat it as minor and offer.
